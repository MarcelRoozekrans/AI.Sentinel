## Acceptance criteria

From the issue. Each has a test named in the tasks.

- With a Rego policy configured, a hook on a CLI host denies a tool call that matches a blocking rule; the agent sees the rule's reasons. Test class `RegoPolicyDenyTests`.
- The denial is recorded in the local audit with the reasons, like other blocks. `RegoPolicyDenyTests`.
- A policy that cannot be read or compiled blocks PreToolUse with an internal-error reason. `RegoPolicyLoadFailureTests`.
- Builtins that reach outside the process are refused. `RegoPolicyLoadFailureTests`.
- With `SENTINEL_HOOK_POLICY_DIR` unset, the hooks behave exactly as before. `RegoPolicyDenyTests` plus the existing suite.
